# WebcamFbt

Webカメラ（1〜2台）の映像から姿勢を推定し、VRChat の OSC トラッカーとして腰・両足の位置と回転を送る Windows 向けアプリです。
SteamVR 用のドライバは不要で、VRChat の OSC トラッカー機能に直接送ります（PC 版・Quest 単体のどちらでも使えます）。

> **現在の状態: v0.1.0**
> カメラ1台での利用（単眼の推定・キャリブレーション・VRChat への送信）は動作確認済みです。
> カメラ2台（ステレオ）の機能は実装済みですが、**実機の2台ではまだ確認していません**（計算は合成データのテストで検算済み）。

## Mac 版（試験版）

Windows を持っていない人向けに、Mac で動かして **Quest 単体の VRChat** に送る版があります（VRChat 自体は Mac では動きません）。
[Releases](../../releases) の `WebcamFbt-<版>-mac.pkg` を開いてインストールします（Apple Silicon と Intel のどちらでも同じファイル）。
機能と画面は Windows 版と同じです。macOS 13.4 以降が必要です。**Mac の実機ではまだ確認していません。**

- Apple の署名・公証をしていないため、最初に開くと「開けません」と出ます。右クリック →「開く」、または
  システム設定 → プライバシーとセキュリティ →「このまま開く」で開けます
- 初回の「開始」でカメラの使用を許可してください
- 実行中は Mac がスリープしません。閉じるボタンでは画面が隠れるだけで動き続け、メニューバーのアイコンから表示・終了できます
- 送信先には Quest の IP アドレスを入れて「反映」を押します（Quest と Mac は同じ Wi-Fi に）
- 新しい版の .pkg を入れると、今の版に上書きされます（設定はそのまま）
- 設定などの保存先は `~/Library/Application Support/WebcamFbt` です

詳しくは [docs/mac.md](docs/mac.md) を参照してください。

## 動作環境

- Windows 10 1903 以降 / Windows 11（64bit）
- DirectX 12 対応の GPU（推奨）。使えない場合は CPU で動きます（遅くなります）
- Webカメラ 1〜2 台（720p / 60fps 対応だと遅延が少なくなります）
- 初回起動時にインターネット接続（モデルのダウンロード、約 70MB）

## ダウンロードとインストール

[Releases](../../releases) から、次のどちらかをダウンロードします。

| ファイル | 内容 |
|---|---|
| `WebcamFbt-<版>-setup.exe` | **インストーラ（おすすめ）**。スタートメニューに登録され、「設定 → アプリ」からアンインストールできます。管理者権限は不要です |
| `WebcamFbt-<版>-win-x64.exe` | インストール不要の単体の exe。好きな場所に置いてそのまま実行できます |

どちらも .NET のインストールは不要です（必要なものはすべて exe に入っています）。

**新しい版への更新**: 新しい版のインストーラを実行するだけで、今入っているものに上書きされます。入れ先や設定・キャリブレーションの結果はそのまま引き継がれます。
アプリを起動したままでも、インストーラが閉じてよいか確認してから更新します。単体の exe の場合は、新しい exe に置き換えてください。

> **「Windows によって PC が保護されました」と表示されたら**
> このアプリにはコード署名をしていないため、Windows の SmartScreen が警告を出します。
> 「詳細情報」→「実行」を押すと起動できます。

### 初回の起動

最初に「開始」を押したとき、姿勢推定のモデルを OpenMMLab の公式サーバーから自動でダウンロードします（約 70MB）。
モデルはライセンスの都合で配布物に含めていません（[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) を参照）。

| 用途 | モデル | 入力サイズ |
|---|---|---|
| 人物検出 | YOLOX-tiny（HumanArt + COCO で学習） | 416×416 |
| 姿勢推定 | RTMPose-m（Halpe26 形式 26 点、body7 で学習） | 192×256 |

ネットに繋がらない環境では、zip を手動でダウンロードして中の `end2end.onnx` を次の名前で **exe と同じフォルダの `models\`** に置いてください。

- `yolox_tiny_humanart.onnx` ← `yolox_tiny_8xb8-300e_humanart-6f3252f9.zip`
- `rtmpose_m_halpe26.onnx` ← `rtmpose-m_simcc-body7_pt-body7-halpe26_700e-256x192-4d3e73dd_20230605.zip`

（URL の場所: `https://download.openmmlab.com/mmpose/v1/projects/rtmposev1/onnx_sdk/`）

## 使い方

右側のパネルの上にある**手順ガイド**に沿って進めます。済んだ手順には ✓ が付き、押すとその設定のタブが開きます。

1. **開始**（「カメラ」タブ）: カメラ・解像度・fps を選んで、下の「開始」を押します。映像に骨格が重なって表示されます
2. **カメラの校正**（「校正」タブ、推奨・2台なら必須）: 印刷したチェッカーボード（既定は内側の交点 9×6、マス目 10×7）を写し、位置と傾きを変えながら毎回少し止めます。15 枚集まると自動で計算して保存します。1マスの大きさは定規で測った値を入れてください
3. **体のキャリブレーション**（「トラッキング」タブ）: 全身が映る位置で、カメラの方を向いて T ポーズで立ち、「キャリブレーション開始」を押します。体の比率・床の高さ・正面の向きを測ります（2台ならカメラの傾きも自動で補正します）
4. **VRChat に送信**（「VRChat」タブ）: 下の「VRChat で使う」を参照

設定とキャリブレーションの結果は保存され、次に起動したときもそのまま使えます。カメラの位置を変えたときは 2・3 をやり直してください。

### タスクトレイで動かす

ウィンドウを **× で閉じても終了せず、タスクトレイ（画面右下の通知領域）に入って裏で動き続けます**（トラッキングと VRChat への送信は止まりません）。VRChat で遊ぶ間は閉じておけます。

- トレイのアイコンを **ダブルクリック** すると画面に戻ります
- **右クリック** のメニューで「表示」「開始 / 停止」「**終了**」ができます。アプリを終わらせるときは「終了」を選んでください
- 隠れている間は映像の表示を止めるので、少し軽くなります
- アプリをもう一度起動したときは、すでに動いている方の画面が出ます（2 つ同時には動きません）

### 画面の見方

- **左上**: カメラの fps、推論の処理時間、使っている推論デバイス（DirectML = GPU / CPU）
- **左下**: 腰・左足・右足・頭・OSC の状態（緑 = 追従中・送信中、黄 = 送信オンだが送るものがない、赤 = 見えていない・エラー、灰 = オフ）と、トラッカーの座標
- **右下**: トラッカーを上から見た図。腰を中心に、両足・頭の位置と向きを表示します（上がカメラ側）。足を前に出すと足の点が上に動きます

うまく映らないときは「取得方式」を DirectShow に変えるか、解像度・fps を下げてみてください。

### VRChat で使う

1. **カメラの置き方**: 全身（頭からつま先まで）が映る位置に、腰くらいの高さで、なるべく水平に置きます
2. **VRChat の設定**: アクションメニュー → Options → OSC → **Enabled** をオンにします
3. **向きを合わせる**: VR でカメラの方を向いて立ち、「VRChat」タブの「向きを合わせる」を押します
4. **VRChat でキャリブレーション**: いつも通り T ポーズでフルボディのキャリブレーションをします

- 送信するトラッカー: 1 = 腰、2 = 左足、3 = 右足
- 頭の位置（`/tracking/trackers/head/position`）も毎フレーム送ります。VRChat はこれを使って、トラッカー全体の位置をアバターの頭に合わせます
- **Quest 単体で使う場合**: このアプリは PC で動かし、送信先に Quest の IP アドレスを入れて「反映」を押します（PC と Quest が同じネットワークにいる必要があります）

### カメラ2台（ステレオ）で使う

2台のカメラで同じ関節を見て三角測量するので、カメラ1台では苦手な「背を向けた姿勢」や「足を後ろに引く動き」も測れます。

1. 「カメラ」タブで「カメラを2台使う」をオンにし、カメラ2のデバイスを選びます（解像度・fps はカメラ1と同じになります）
2. 2台の両方に全身が映るように、1m 前後離して置きます
3. 「校正」タブでカメラの校正をします（2台の両方に写る位置でチェッカーボードを動かします）
4. 校正が済むと、自動でステレオ（三角測量）に切り替わります。左下に「方式 ステレオ」と精度の目安（三角測量できた点の数・誤差・左右の脚の長さの差）が出ます

### 平滑化の調整（One Euro Filter）

「トラッキング」タブの「詳細: 平滑化」で調整できます。

| 症状 | 調整 |
|---|---|
| 止まっているのにトラッカーが震える | min cutoff を下げる |
| 動きについてこない・遅れる | beta を上げる |
| 速く動くと飛ぶ・暴れる | beta を下げる |

### カメラ1台での推定の仕組みと限界

- **距離**: 「身長から求めた骨の長さ」と「画像上の長さ」の比から、カメラからの距離を求めます。身長の設定が大きくずれていると、距離と動きの大きさがずれます
- **体の向き**: 肩幅の縮み具合と、鼻の位置から求めます。**カメラに背を向けると正しく推定できません**
- **足の前後**: 太ももや足の甲が縮んで見える分だけ前に出ているとみなします。**足を後ろに引く動きは前に出したのと区別できません**

これらはカメラ2台（ステレオ）で改善されます。

### 保存されるデータ

`%LOCALAPPDATA%\WebcamFbt\` に保存します。

| ファイル | 内容 |
|---|---|
| `settings.json` | 画面の設定と体のキャリブレーションの結果 |
| `calibration.json` | カメラの校正の結果（カメラ・解像度ごと） |
| `models\` | ダウンロードしたモデル |

インストーラ版をアンインストールするときに、これらも消すか尋ねます。単体の exe の場合は、不要になったらこのフォルダを手で消してください。

- **新しい版に更新しても、設定とキャリブレーションの結果はそのまま引き継がれます**。インストーラは更新の前に、念のため `backup\<更新前の版>\` に写しを取ります
- 新しい版がファイルをうまく読めなかったときは、既定値で起動しますが、元のファイルは `settings.json.<日時>.bak` のような名前で残します（上書きして消すことはしません）

### 新しい版の通知

1 日に 1 回、GitHub の Releases に新しい版が出ていないかを確かめ、出ていれば画面の上（トレイに隠れているときはトレイの通知）で知らせます。
送るのはアプリ名と版だけです。「カメラ」タブの「アプリ」で、オフにしたり今すぐ確かめたりできます。

## 開発者向け

### ビルドと実行

[.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0) が必要です。

```powershell
dotnet test tests\WebcamFbt.Core.Tests -c Release
dotnet run --project src\WebcamFbt.App -c Release
```

Visual Studio 2026 では `WebcamFbt.slnx` を開いて実行できます。

### 配布物を作る

[Inno Setup 6](https://jrsoftware.org/isinfo.php) が必要です。版は `Directory.Build.props` の `<Version>` です。

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-release.ps1
```

テスト → 単一 exe（self-contained）→ インストーラの順に作り、`artifacts\release\` に出力します。

### 構成

```
src/
├─ WebcamFbt.App/     WPF の画面（View / ViewModel）
├─ WebcamFbt.Core/    外部ライブラリに依存しない部分（3D 化・三角測量・キャリブレーション・トラッカー計算・フィルタ・座標変換・設定の保存）
├─ WebcamFbt.Osc/     OSC のエンコードと VRChat への送信
└─ WebcamFbt.Vision/  カメラ取得、ONNX 推論、チェッカーボードの校正、描画、処理パイプライン
tests/
└─ WebcamFbt.Core.Tests/  xUnit（OpenCV の校正計算も合成データで検算）
installer/            Inno Setup のスクリプト
scripts/              配布物を作るスクリプト
```

処理の流れ:

```
[カメラスレッド] ─最新フレーム→ [推論スレッド] 検出→切り出し→キーポイント推定→3D 化→トラッカー計算・平滑化
                                        │                                   │ 最新のトラッカー
                                        └─最新プレビュー→ [UI]              └→ [OSC 送信スレッド] → VRChat
```

- 各スレッド間は「最新の 1 個だけ」を受け渡すので、処理が追いつかなくても遅延がたまりません
- 人物検出は重いので毎フレームは動かさず、前フレームのキーポイントから次の切り出し範囲を決めます
- 姿勢推定は `IPoseEstimator2D` で抽象化してあり、BlazePose などに差し替えられます
- 2台のときは、各カメラの推論結果を撮影時刻で組にして三角測量します

設計の詳細は [docs/design.md](docs/design.md) を参照してください。
